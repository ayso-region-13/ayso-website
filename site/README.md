# AYSO Region 13 — Static Site

Built with [Eleventy (11ty)](https://www.11ty.dev/) + Tailwind CSS. Hosted on Cloudflare Pages.

## Local Development

```bash
cd site/
npm install
npm start
```

Opens at http://localhost:8080

## Building

```bash
npm run build
```

Output goes to `_site/`.

## Cloudflare Pages Setup

1. Push this repository to GitHub
2. In Cloudflare Pages → Create a project → Connect to Git
3. Set:
   - **Root directory:** `site`
   - **Build command:** `npm run build`
   - **Build output directory:** `_site`
4. Deploy

## Re-running Scripts

If content files are edited in `/content/`, re-run the migration:
```bash
node scripts/migrate-content.js
```

To re-process photos (after adding new photos to Google Drive):
```bash
bash scripts/process-photos.sh
```

## Site Structure

```
src/
├── _data/
│   ├── navigation.js   ← Full nav structure (edit to add/remove pages)
│   └── site.json       ← Site metadata (phone, email, address, etc.)
├── _includes/
│   ├── base.njk        ← HTML shell, header, nav, footer
│   ├── page.njk        ← Standard content page layout
│   └── home.njk        ← Home page layout
├── assets/css/
│   └── tailwind.css    ← Input CSS (compiled to style.css)
├── images/             ← Web-optimized photos + logo.svg
└── [content pages]     ← Generated by migrate-content.js
```
